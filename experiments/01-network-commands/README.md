# Experiment 01 — Network commands and packet capture

Ubuntu/Linux: `ip addr`, `ip route`, `ss -tuln`, `nslookup example.com`, `traceroute example.com`, `ping -c 4 example.com`.
Windows CMD: `ipconfig`, `netstat -ano`, `nslookup example.com`, `tracert example.com`, `ping example.com`, `hostname`, `getmac`, `arp -a`, `tasklist`.
Capture traffic with Wireshark, run a ping, stop capture and apply display filter `icmp`. Save actual screenshots.
